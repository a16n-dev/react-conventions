## Description
Prefer using the following casing conventions for the type of identifier:

| Example | Type | Description |
|-|-|-|
| `IconButton` | React component | PascalCase |
| `ButtonVariants` | Enum | PascalCase |
| `buttonVaraint` | Variable | camelCase |
| `BUTTON_VARIANTS` | Constant | UPPER_CASE |
| `ButtonVariant` | Type | PascalCase |
| `getButtonVariant` | Function | camelCase |
